# Easy App

**A structured, end-to-end development protocol for building high-quality applications.**

Easy App is an AI Agent Skill that provides a systematic approach to application development, from initial product discovery to final delivery. It guides AI agents through requirement clarification, Apple Human Interface Guidelines (HIG)-informed design, engineering foundation setup, iterative implementation, and quality assurance.

Rather than jumping straight into coding, Easy App establishes a disciplined development process that reduces unnecessary rework, improves design consistency, and ensures engineering decisions are made with long-term maintainability in mind.

## Core Capabilities

- **Product Discovery:** Clarifies target users, platforms, core features, distribution requirements, and technical constraints before development begins.
- **Apple Design Standards:** Translates Apple HIG principles into measurable design specifications, including typography, spacing, colors, interaction dimensions, materials, and platform-specific requirements.
- **Day 0 Engineering Foundation:** Establishes Git version control, semantic versioning, automated verification, design tokens, reusable components, data migration strategies, and distribution pipelines.
- **Iterative Development:** Enforces a small-step development cycle with immediate build verification, testing, visual inspection, and version tagging.
- **Quality Assurance:** Provides structured design and engineering checklists to validate the application before delivery.

## Development Philosophy

Easy App is built around three principles:

1. **Product thinking before coding.** Understand what needs to be built, who it serves, and how it will be distributed before making technical decisions.
2. **Engineering foundations before features.** Invest in project infrastructure early to prevent avoidable technical debt and expensive rework.
3. **Measurable specifications over subjective judgment.** Turn vague visual feedback into concrete, testable design requirements.

## Workflow

`Discovery → Design Specifications → Day 0 Foundation → Feature Development → Verification → Delivery`

Each phase has defined procedures, reference materials, and acceptance criteria. Critical project stages should not be skipped.

## Compatibility

Designed for AI agents that support the open Agent Skills standard, with a platform-independent core instruction set.

## Intended Use

Easy App is suitable for:
- Building new applications from scratch.
- Refactoring or rebuilding existing projects.
- Preparing applications for distribution and release.
- Evaluating technical feasibility and technology stacks.
- Conducting design reviews and engineering retrospectives.

**Easy App turns application development from an improvised coding process into a structured, verifiable engineering workflow.**
